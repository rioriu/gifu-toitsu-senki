# 市町村の境界・アイコンの確認結果

確認日：2026年10月16日。対象：ver. 0.1.6。

## 修正対応（ver. 0.1.7）

以下の5件を対応した。下の確認結果は、修正前の記録として残す。

- 安八町：「安八百梅園の梅」に差し替えた。丸い花びらと枝を描き、本巣市の淡墨桜とも区別した。
- 可児市：「ローズガーデンのバラ」に名前を更新した。
- 七宗町：「20億年前の石」に名前を更新した。
- 揖斐川町：徳山ダムを、湖の手前に幅のある石積みの斜面がある絵にした。
- 大垣市：主な名前を大垣地域へ移し、上石津・墨俣に拡大時の補足名を付けた。可児市の飛び地にも補足名を付けた。補足名は他の名前と重なるときに隠し、ふりがな設定にも合わせる。境界と隣接関係は変更していない。

修正後は、幅375pxで地図とアイコンのSVGを画像にして見た目を確認した。地図の実装を使った簡易DOMで、全県では補足名を隠すこと、拡大時に表示されること、5段階の縮尺とふりがなの有無で補足名が他の名前と重ならないことを検証した。全42アイコンのSVG構文、JSの構文、追加分を含む45個の名前の基準点が領域内にあることも確認した。ブラウザの実画面での確認は環境の制限により未実施。

## 結果

42市町村の欠落、コードの重複、大きな境界の取り違えは見つからなかった。アイコンも42件そろっている。修正候補は下の5件。ゲームのデータ・表示は変更していない。

「境界が正確」と断定できる検査ではない。県の行政区画図との目視比較と、現在のSVG内の整合性検査を行った。元の国土数値情報との座標単位の比較は行っていない。

## 修正候補

### 1. 安八町：梨を町の代表とする根拠を確認したい

- 場所：`js/icons.js:63`。表示名は「安八の梨」。
- [町の観光ガイド](https://www.town.anpachi.lg.jp/musubuterasu/cmsfiles/contents/0000001/1272/gaidobukku.pdf)では、野菜・うどん・梅の加工品などが特産品として紹介されている。今回確認できた町の資料では、梨を町の代表とする根拠は見つからなかった。
- 梨が生産されていないと断定するものではない。[JAにしみの](https://www.jan.or.jp/products/)は梨を地域の産品に挙げているが、対象は複数の市町にまたがる。
- 提案：「安八百梅園の梅」にすると、町との結びつきが明確で、現在の42アイコンとも区別できる。[安八町の説明](https://www.town.anpachi.lg.jp/0000000376.html)。
- 判定：要裏付け。題材変更の優先候補。

### 2. 可児市：バラは適切だが、表示名が旧名称

- 場所：`js/icons.js:80`。「花フェスタのバラ」。この名前はスタート地点の詳細にも表示される（`js/ui.js:1227`）。
- 公園は2021年10月9日に「ぎふワールド・ローズガーデン」へ改称している。[公園の公式説明](https://gifu-wrg.jp/about/)。
- 提案：アイコンはそのまま使い、名前を「ローズガーデンのバラ」などにする。
- 判定：名称更新を推奨。バラという題材には問題なし。

### 3. 七宗町：「日本最古の石」は施設名と科学的な説明を分けたい

- 場所：`js/icons.js:93`。
- 七宗町の20億年前の石は地域を代表する題材として適切。ただし、津和野町では25億年前の岩石の発見が2019年に公表されている。[津和野町の発表](https://www.town.tsuwano.lg.jp/www/contents/1554855227785/index.html)。
- 「日本最古の石博物館」は現在も使われている施設名。[博物館公式サイト](https://ishihaku.hichiso.jp/)。施設名そのものを誤りと扱う必要はない。
- 提案：「20億年前の石」か「日本最古の石博物館」にする。前者なら短く、石を描いた絵とも合う。
- 判定：説明の正確さを上げるための表現更新。

### 4. 揖斐川町：徳山ダムの構造が絵に反映されていない

- 場所：`js/icons.js:65–68`。
- 現在は、灰色の壁の中央から水が流れる一般的なダムの絵に見える。徳山ダムは岩や土を盛ったロックフィルダム。[岐阜県観光連盟の説明](https://www.kankou-gifu.jp/model/detail_12.html)。
- 提案：幅のある石積みの斜面と、その奥の湖を描く。今の絵でも「ダム」とは分かるため、名称更新より優先度は低い。
- 判定：題材は適切。実物らしさの改善候補。

### 5. 大垣市：名前が上石津地域にしか出ない

- 場所：`js/map-data.js` の `21202` の `lx:152.7, ly:1063.3`。`js/ui.js:42–52` は市町村ごとに名前を1つ置く。
- 形は3つあり、大垣地域・上石津地域・墨俣地域の飛び地を保持している。ところが名前の位置は南西の上石津地域にある。県の図は大垣地域に名前を置き、ほかの地域との関係を引き出し線で示している。[県の行政区画図](https://www.pref.gifu.lg.jp/uploaded/attachment/511171.pdf)。
- 提案：主ラベルを大垣地域に移し、ズーム時に上石津・墨俣にも「大垣市（上石津）」「大垣市（墨俣）」などを補う。境界そのものをつなげる必要はない。
- 可児市の飛び地も保持されているが、名前は本体側だけ。飛び地の表示を直す場合はあわせて扱うとよい。
- 判定：境界の誤りではなく、所属を読み取りやすくする改善。

## 境界の検査

比較資料は[岐阜県統計書・令和7年](https://www.pref.gifu.lg.jp/page/513186.html)掲載の行政区画図（図上の基準日：令和7年4月1日）。県全体の輪郭、市町村の配置、細長い関市・本巣市、大垣市の3地域、可児市の飛び地などを比較し、大きな取り違えは見つからなかった。

`map-data.js` をNodeのVMで読み出し、SVGの各 `M…Z` を多角形としてShapely 2.2.0で検査した。点はラベルの基準点を使い、面積・距離の単位はSVG座標。実際の平方キロメートルではない。

| 検査 | 結果 |
| --- | --- |
| 市町村数・コードの一意性 | 42件、重複なし |
| ゲームの市町村情報・アイコンとの対応 | 欠落・余分なコードなし |
| 圏域ごとの数 | 岐阜9、西濃11、中濃13、東濃5、飛騨4 |
| 個々の多角形の自己交差など | 無効な多角形なし |
| 名前の基準点 | 42件すべて自分の領域内 |
| 隣接データ | 自分自身・未定義コード・片方向だけの登録なし |
| 隣接と図形の接触 | 登録100組すべて距離0。未登録の組はすべて離れている（最小距離約2.484） |
| `area` と多角形面積 | 1％を超える差なし |

境界線は完全には共有されておらず、小さな重なりと隙間がある。市町村面積の合計と全領域の和集合の差は約335.924、合計面積約688,580.5の約0.049％。最大の重なりは高山市・飛騨市の約18.386。簡略化の際のずれと整合するが、生成手順が残っていないため原因は確定できない。これだけを理由に手作業で境界を描き直す必要はない。

元データの年次、ファイル名、投影方法、簡略化の条件、生成スクリプトはリポジトリで確認できなかった。将来地図を更新するときは、共有する境界を一度だけ簡略化する手順と、元データの情報を残したい。

## 見た目の確認と残る確認

アイコン42件をSVGから画像にして、64pxと28pxの一覧で確認した。線と色は統一され、同じ美濃焼でも形を変えて見分けられる。鵜飼・干し柿・楼門などは小さくすると細部が減るが、図柄全体は残る。

28pxの一覧は幅375pxの確認用画像として生成したもので、実際のゲーム画面のスクリーンショットではない。ブラウザでのローカルファイル表示が環境の制限で使えなかったため、375pxでのゲーム内の重なり、実際の文字幅、ズーム時の見え方、タップ操作は今回未確認。ゲーム画面は変更していない。

人口・ゲーム用の能力値・偉人のゆかりの地の妥当性は、この確認の対象外。
