# 岐阜統一戦記 ゲーム仕様書（v0.1）

Oct 11, 2026 · @Yoshinobu Uno

## コンセプト

プレイヤーは岐阜県内の1市町村の首長になり、連携協定と合併を重ねて県内42市町村の統一を目指す。戦国シミュレーションの「国盗り」を、武力ではなく予算・産業・住民の支持で置き換えた現代版。

- ジャンル：ターン制の地域経営×陣取りシミュレーション
- 遊ぶ場所：スマホのブラウザ（縦画面）。インストール不要、PCでも遊べる
- プレイ時間：1年（12ターン）で約10分、県内統一まで1〜2時間。途中セーブ可
- 想定プレイヤー：岐阜県民・出身者、歴史シミュレーション好き
- 売り：地元ネタ（鵜飼、高山祭、美濃焼、関の刃物、飛騨牛）と、平成の大合併を自分の手でやり直せる面白さ
- 仮タイトル：「岐阜統一戦記」。既存作品の名称・ロゴ・キャラクターは使わず、すべてオリジナル

## 市町村パラメータと特産

各市町村は6つの数値と「特産タグ」を持つ。人口は県の統計を丸めた値を使い（例：岐阜市 約40万人）、ほかはゲーム用に調整した値にする。

| 項目 | 範囲 | 意味 |
| --- | --- | --- |
| 人口 | 実数（千人単位） | 税収と住民投票の重みになる |
| 財源 | 億円 | 毎ターンの収入。コマンドの支払いに使う |
| 産業力 | 0〜100 | 税収の伸び。企業誘致で上がる |
| 観光力 | 0〜100 | イベント時の収入ボーナス |

| 防災力 | 0〜100 | 豪雨・豪雪イベントでの被害を減らす |

## ゲームの流れ

1ターン＝1か月。プレイヤーは毎ターン「行動力（AP）」を使ってコマンドを実行する。APは基本3で、自陣営の市町村が5つ増えるごとに＋1。

1. 月初イベント：季節イベントや災害、ランダムな出来事が起きる
2. 収入：人口と産業力から税収、観光力から観光収入が入る
3. コマンド：プレイヤーがAPを使って行動する
4. ライバルの行動：AI首長が同じように内政・協定・合併を進める
5. 月末集計：人口の増減、満足度の変化、合併協議の進行を反映

| 種類 | コマンド | 効果 | AP / 費用 |
| --- | --- | --- | --- |
| 内政 | 産業振興 | 産業力＋ | 1 / 中 |
| 内政 | 観光PR | 観光力＋ | 1 / 小 |
| 内政 | 子育て支援 | 満足度＋、人口減少を抑える | 1 / 中 |
| 内政 | 防災対策 | 防災力＋ | 1 / 中 |
| 内政 | 企業誘致 | 成功すると産業力と人口が大きく増える | 2 / 大 |
| 人事 | 人材登用 | 新しい人材を雇う | 1 / 小 |
| 外交 | 交流事業 | 隣の市町村との関係度＋ | 1 / 小 |
| 外交 | 連携協定 | 協定を結ぶ（次の節） | 1 / なし |
| 外交 | 合併協議の申し入れ | 合併の手続きを始める（次の節） | 2 / 中 |
| 外交 | 情報収集 | ライバルの数値と動きを見る | 1 / 小 |

## 拡大の仕組み

武力の代わりに「関係度」と「住民の賛成」で領地を広げる。合併できるのは隣り合う市町村だけで、協定・協議・住民投票の3段階を踏む。

&#91;embedded content: 合併の流れ · 3段階、分岐2つ\]

ライバルが同じ相手に協議を申し入れると「条件の競り合い」になり、ここが戦国シミュレーションの合戦に当たる見せ場になる。

- 関係度：隣り合う市町村ごとに0〜100。交流事業や協定で上がり、強引な申し入れや否決で下がる
- 連携協定：関係度50以上で締結。収入ボーナスが付き、相手の数値が見えるようになる
- 合併協議：関係度70以上で申し入れ、3ターン続く。期間中に相手の満足度を上げると有利
- 住民投票の賛成率（案）：50％＋（自陣営の満足度−相手の満足度）×0.5＋人材の交渉力ボーナス＋特産の相性−人口差ペナルティ
- 可決：相手は自陣営の「地区」になり、元の数値と特産タグを保ったまま組み込まれる。数ターンは「合併疲れ」で満足度が少し下がる
- 否決：関係度が下がり、2ターンは再協議できない
- 切り崩し：ライバル陣営の地区で満足度が30未満になると「分離運動」イベントが起き、自陣営に引き抜ける
- 魅力：産業力と観光力の平均（陣営は人口で重みづけ）。相手より10以上高いと隣の市町村との関係度が毎月自然に上がり（最大+3）、住民投票の賛成も増える（−5〜+8）。陣営の魅力50・60で同時に進められる合併協議が1件ずつ増える
- 産業力・観光力は毎月少しずつ下がる（特産の分は残る）。人口もゆるやかに減り、満足度と産業力が高いと減り方が小さい

### 対戦要素（追加）

合併の流れに加えて、ライバル陣営と直接ぶつかる場面を3つ用意する。

- 首長選挙：各市町村で4年ごとに選挙がある。ライバル陣営の市町村にも候補を立てられ、投票日までの3か月、両陣営が演説会や政策公約に行動力と財源をつぎ込む。得票で所属が入れ替わる
- 誘致合戦：大型の企業進出が発生すると、隣り合う陣営同士が補助金額を出し合って奪い合う。勝った側は産業力と人口が大きく伸びる
- 条件の競り合い：同じ市町村に複数の陣営が合併協議を申し入れたとき、条件の上乗せ勝負になる

## 人材とイベント

人材は戦国SLGの「武将」に当たる。すべて架空のキャラクターで、実在の現職首長や存命の人物は登場させない（実在の人物は偉人アドバイザーの歴史人物だけ）。

- 能力：政策・交渉・企画・人望（各1〜100）
- 役職：副市長（全体ボーナス）、企画課長（内政の効果アップ）、交渉担当（賛成率アップ）、観光大使（観光力アップ）
- 合併すると、相手側の人材の一部が自陣営に加わる
- 偉人アドバイザー：岐阜ゆかりの歴史人物（斎藤道三、織田信長、竹中半兵衛、明智光秀など）がカードとして期間限定で助言し、能力ボーナスをくれる
  - ゆかりの地を自陣営に持つと、人材の画面から招ける（行動力1・15〜35億円）。助言は6か月で、ゆかりの地を失うとその場で去る。去ったあと12か月はどの陣営も招けない
  - 同時に招けるのは1人、市町村が8つ以上で2人。1人の偉人は同時に1つの陣営にしかつかない。ライバルも招く
  - 助言中は台帳に、効果に合わせた「いま手を打つとよい市町村」のひとことが出る

## 勝利・敗北条件と難易度

基本の勝利は県内42市町村すべてを自陣営にすること。短く遊べるモードも用意する。

- 統一勝利：42市町村すべてを自陣営にする
- 圏域制覇モード：スタート地点の圏域を統一したら勝ち。ライバルは圏域の中には置かず、圏域の外で接するいちばん大きな市町村に1陣営を置く。長さは圏域の市町村数で変わる（飛騨4・東濃5は短め、岐阜9・西濃11はふつう、中濃13は長め）
- スコア勝利：10年（120ターン）経過時点で「人口×満足度」が最も高い陣営の勝ち
- 敗北：財源のマイナスが3ターン続く（財政破綻）、満足度20未満でリコール成立、自分の市町村がライバルに合併される

難易度はスタートする市町村で決まる。ライバルAI首長は3〜5人で、県内の主要都市からスタートする。

| 難易度 | スタート地点の例 | 特徴 |
| --- | --- | --- |
| やさしい | 岐阜市、大垣市 | 人口と財源が多く、隣接する市町村も多い |
| ふつう | 関市、多治見市、高山市 | 特産が強く、伸ばし方に個性が出る |
| むずかしい | 町からスタート | 財源が少なく、協定で生き残る立ち回りが必要 |
| 超むずかしい | 白川村、東白川村 | 人口が非常に少なく、観光や人材で逆転を狙う |

## スマホUI・技術仕様

縦画面・片手操作を前提にし、サーバーなしで動く静的なWebページとして作る。

画面構成（上から）：

1. ステータスバー：年月、財源、AP、自陣営の市町村数
2. マップ：陣営ごとに色分け。ピンチでズーム、タップで市町村を選択
3. ボトムシート：選んだ市町村の数値とコマンドボタン。上にスワイプで詳細表示
4. 下部タブ：マップ／陣営一覧／人材／ログ

- ボタンは最小44px角。主要な操作は画面下半分に集める
- 演出は短く（1回1秒以内）、スキップ可能にする

| 項目 | 仕様 |
| --- | --- |
| 実装 | HTML・CSS・JavaScript（フレームワークなし、または軽量なもの） |
| 地図 | SVG。国土数値情報の行政区域を簡略化して使用し、出典を表記 |
| データ | municipalities.json（数値・特産）、adjacency.json（隣接）、events.json（イベント） |
| セーブ | ブラウザ内保存（localStorage）、3スロット＋オートセーブ |
| 配信 | 静的ホスティング（GitHub Pagesなど）またはClaudeのアーティファクト |
| 容量目標 | 合計2MB以下、通信が弱くてもすぐ起動 |
| 任意 | PWA化してホーム画面に追加、オフラインで遊べる |
