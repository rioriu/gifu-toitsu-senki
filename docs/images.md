# 画像の依頼書

岐阜統一戦記で使うイラストの一覧と、描くときの決まり。
このファイルの画像（WebP・JPEG）は Codex に依頼する。アイコン類（市町村ごとのアイコン・誘致合戦の企業）は SVG でコードの中に作るので、ここには含めない。市町村アイコンは `js/icons.js`（一覧は `tools/icons.html`）。

依頼する範囲は、下の一覧の画像ファイルを指定のパスに置くところまで。画面への組み込みは済んでいるので、HTML・CSS・JS を変える必要はない。ファイルを置けばその場所に出て、まだないものは出ない（画像なしの今の見た目のまま）。1枚ずつ届けてかまわない。

## 1. 画風（全部の画像で共通）

**現代的な和風のフラットイラスト。** 木版画を思わせる、くっきりした輪郭線と平塗りで描く。グラデーションは控えめにし、うっすらと和紙の質感を入れる。写真のような写実表現にはしない。

- 色：画面の色に合わせる。地の色は生成り・和紙色（#efe6d2 前後）。差し色は次の4つ。
  - 朱（#cf4526）：プレイヤーの陣営
  - 藍（#2c5fa3）・萌黄（#5b8a24）・紫（#874c9b）：ライバルの陣営
  - 地面・山は、くすんだ緑と灰青（#d3dccd・#566771 前後）
- 線：濃い藍墨色（#1b2830 前後）で、太さをそろえる。全部の画像で同じ線の太さ・同じ塗り方にして、1つのシリーズに見えるようにする
- 雰囲気：明るく、少しユーモアがあり、品がある。地元の人が見て「岐阜らしい」と思える
- ライトモードとダークモードのどちらの画面にも出るので、透過は使わず、背景まで描き込む

画像生成ツールに渡すときの共通の指示（各画像の説明の前に付ける）：

## 2. 著作権・トラブルを避けるための決まり

必ず守ること。

1. **既存の作品をまねない。** ゲーム・アニメ・漫画・ドラマのキャラクターや画風に寄せない。プロンプトに作品名・作家名・スタジオ名・ゲーム会社名を入れない（浮世絵の特定の作品や絵師の名前も入れない）
2. **実在の人に似せない。** 俳優・政治家・首長・存命の人物の顔に寄せない。歴史人物も、大河ドラマなどで演じた俳優の顔にしない
3. **現存する肖像画や写真をなぞらない。** 歴史人物は「一般に知られている特徴」（髪形・服装・持ち物）だけを手がかりにして、構図・ポーズ・顔立ちは新しく描く。島崎藤村・杉原千畝は写真が残る人物なので、とくに写真の構図を再現しない
4. **ロゴ・文字を入れない。** 商標、企業名、看板の文字、市町村章、ゆるキャラ・マスコット、観光ポスター、実在の商品パッケージを入れない。文字はすべて画面のほうで入れる（画像の中の日本語は崩れやすいため）。サイン・透かしも入れない
5. **家紋・旗印は描かない。** 旗やのぼりは無地か、簡単な模様（線・市松・波など）にする
6. **名所は一般的な特徴で描く。** 特定の観光写真や絵はがきの構図を再現しない。実在する企業の工場・建物も描かない
7. **災害を悲惨に描かない。** けが人、壊れた家、流される人は描かない。備える人・見守る人を中心にする
8. **人物の扱いに気をつける。** 歴史人物は敬意をもって描き、からかう表現にしない。大谷吉継は白い頭巾の姿で描き、病気を強調しない
9. **記録を残す。** 生成ツールを使ったときは、公開・商用利用が許されているツールを使う。ツール名とプロンプトを `docs/images-credits.md` に画像ごとに書き残す

## 3. 形式と容量

- 置き場所：`img/` の下（サブフォルダは一覧のとおり）
- 形式：WebP（画質75〜80、sRGB）。SNS用の `img/ogp.jpg` だけ JPEG
- サイズ：一覧の「ピクセル」どおり（スマホの2倍の解像度）
- 容量：1枚ごとの上限を守る。画像全体で約2.3MB以内。画像はその画面を開いたときだけ読み込むので、起動時に読むのはタイトルの絵だけ（起動時の合計1MB以下を守るため、`title.webp` の上限はとくに守る）
- 元データ（高解像度のPNGなど）はリポジトリに入れない
- 大事なものは中央に置く。画面の幅によって端が切れる（「安全範囲」を参照）
